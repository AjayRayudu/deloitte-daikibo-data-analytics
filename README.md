# Deloitte Data Analytics — Daikibo Telemetry Analysis

## Project Overview

This project was completed as part of the **Deloitte Data Analytics Job Simulation on Forage**.

The project focuses on analyzing telemetry data collected from **Daikibo**, a global manufacturing company operating factories across four locations:

* 🇯🇵 Daikibo Factory Meiyo — Tokyo, Japan
* 🇯🇵 Daikibo Factory Seiko — Osaka, Japan
* 🇩🇪 Daikibo Berlin — Berlin, Germany
* 🇨🇳 Daikibo Shenzhen — Shenzhen, China

Each factory contains **9 different types of machines**, with telemetry data recorded every **10 minutes** throughout May 2021.

The objective was to analyze the telemetry data and answer two key business questions:

1. **Which Daikibo location experienced the most machine breakdowns?**
2. **Which machines broke down most often at that location?**

---

## Business Questions

### Question 1

**In which location did machines break the most?**

The telemetry data was analyzed across all four Daikibo factories to identify the location with the highest number of machine failures.

### Question 2

**What machines broke most often at that location?**

After identifying the location with the highest number of breakdowns, the machine-level failure data was analyzed to determine which machine types experienced the most failures.

---

## Analysis

The telemetry data was aggregated by factory location to compare machine breakdown frequency.

The analysis then focused on the factory with the highest number of machine failures.

Within that factory, machine-level breakdown counts were compared to identify the machines experiencing the most failures.

---

## Business Impact

The analysis provides Daikibo with a clearer understanding of where machine failures are concentrated.

The results could support:

* Preventive maintenance planning
* Machine replacement decisions
* Factory-level maintenance prioritization
* Reduction of machine downtime
* Improved operational efficiency

By identifying machines that fail most frequently, Daikibo can prioritize maintenance resources toward the equipment with the greatest potential operational impact.
